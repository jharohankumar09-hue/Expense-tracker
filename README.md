# Personal Expense Tracker

## Overview
A beginner-friendly Python project that helps users record, manage and analyse their daily expenses.

## Features
- Add and view expenses
- Analyse total, average, highest and lowest expenses
- Search expenses by category
- Set a budget and check remaining balance

## Technologies Used
- Python
- VS Code
- Git and GitHub

## How to Run
1. Install Python.
2. Download the project from GitHub.
3. Open the project folder in VS Code.
4. Run `python main.py` in the terminal.
5. Select an option from the menu.

## Testing
Test each menu option by adding expenses, viewing them, searching categories and checking budget status.
