Personal Expense Tracker

1. Problem Statement

Managing daily expenses manually can be difficult, especially for students who have a limited budget. It can be challenging to keep track of spending, calculate total expenses and identify where money is being spent.

The Personal Expense Tracker is a Python-based, menu-driven application designed to help users record, view, search and analyse their daily expenses. It also allows users to set a budget and monitor their spending.

2. Scope of the Project

The project is a simple, console-based application developed using Python. It focuses on basic expense management and budget tracking.

Users can add expenses with an amount, category, date and description. They can view their recorded expenses, search by category and calculate their total, average, highest and lowest expenses. They can also set a budget and check their remaining balance.

The current version stores expenses temporarily while the program is running. It does not require a database or internet connection.

3. Target Users

- Students who want to manage their pocket money.
- Individuals who want to track their daily expenses.
- Beginners who need a simple tool for personal budget management.

4. High-Level Features

Add Expense

Allows users to enter the amount, category, date and description of an expense.

View Expenses

Displays all recorded expenses in an organized format.

Analyse Expenses

Calculates the total, average, highest and lowest expenses.

Search Expense

Allows users to find expenses by entering a category.

Set Budget

Allows users to set a personal spending budget.

Budget Status

Calculates total spending and shows the remaining budget or the amount by which the budget has been exceeded.
